Achievements

Bangla Iskool is a cross-platform educational game (Android & iOS) that makes learning Bengali engaging and enjoyable for kids.

  • Gameplay programming: crafted core gameplay mechanics for a seamless and immersive learning experience.
  • In-app purchase system for premium features and content.
  • Notification system using the OneSignal SDK to keep users engaged and informed.
  • Firebase Analytics for data-driven decisions and improvements.
  • Facebook SDK integration for social connectivity and sharing achievements.
  • Letter recognition with OpenCV and Python: kids write a Bangla letter and the system scores it based on accuracy.

Bangla Iskool is not just a game — it's a unique educational platform that combines entertainment with learning. I'm proud to have contributed my expertise in game development, programming, and integration to help learners embark on an interactive language-learning journey.

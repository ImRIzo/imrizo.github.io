About the project

An interactive virtual book that combines Computer Vision with Unity 3D. Hand gestures detected through MediaPipe are used as input - a simple swipe of the hand turns to the next page of the book.

  • Real-time hand gesture detection via MediaPipe running inside Unity.
  • Gesture-to-interaction mapping: turn pages, go back, and navigate content without touching anything.
  • Projected book visuals rendered over the physical space for a natural reading experience.
  • Proof of concept for hands-free interactive installations and exhibitions.

This project was my deep-dive into combining Computer Vision with Unity 3D - turning raw camera input into intuitive, touch-free interaction.
